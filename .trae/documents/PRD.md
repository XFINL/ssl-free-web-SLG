# SSL证书申请平台 - 产品需求文档

## 1. 项目概述

### 项目名称
SSL证书申请平台

### 项目类型
企业级HTTPS证书申请网站

### 核心功能
为用户提供便捷的SSL证书申请服务，支持泛域名和单域名两种类型

### 目标用户
- 网站开发者
- 企业IT部门
- 个人站长

---

## 2. 首页设计规范

### 2.1 视觉风格

#### 整体美学
- **设计理念**: 玻璃态（Glassmorphism）+ 液态效果
- **圆角**: 高圆角设计（border-radius: 20px-30px）
- **透明度**: 玻璃高透明度背景（background: rgba(255, 255, 255, 0.1)）
- **背景**: 深黑色背景（#000000 或 #0a0a0a）
- **文字**: 纯白色文字（#ffffff）

#### 玻璃态效果参数
```
backdrop-filter: blur(20px);
background: rgba(255, 255, 255, 0.08);
border: 1px solid rgba(255, 255, 255, 0.15);
box-shadow: 0 8px 32px rgba(0, 0, 0, 0.3);
```

### 2.2 页面结构

#### 顶部区域
- **LOGO区域**
  - 位置：页面顶部居中或左对齐
  - 尺寸：适当的大小（建议 120px - 160px 宽度）
  - 样式：纯文字或SVG图形，白色主题

#### 主内容区域
- **搜索/输入框**
  - 位置：LOGO正下方
  - 宽度：占容器80%-90%
  - 高度：50px-60px
  - 右侧图标：阿里巴巴图标库放大镜图标（icon-search）
  - 样式：玻璃态效果，内边框高光

#### 价格模块区域
- **模块1：泛域名证书**
  - 产品名称：泛域名SSL证书（Wildcard SSL）
  - 价格：15元/张
  - 展示形式：玻璃卡片
  - 视觉权重：高

- **模块2：单域名证书**
  - 产品名称：单域名SSL证书（Single Domain SSL）
  - 价格：5元/张
  - 展示形式：玻璃卡片
  - 视觉权重：次高

#### 价格卡片通用规范
- 圆角：24px
- 背景：玻璃态半透明
- 边框：1px solid rgba(255, 255, 255, 0.1)
- 内边距：30px-40px
- 间距：卡片之间 20px-30px

## 3. 技术实现规范

### 3.1 技术栈
- HTML5
- CSS3（独立文件）
- Vanilla JavaScript（独立文件）

### 3.2 项目结构
```
/workspace/
├── index.html          # 首页HTML
├── css/
│   └── styles.css      # 所有样式文件
├── js/
│   └── main.js         # 所有交互逻辑

```

### 3.3 外部依赖
- 阿里巴巴图标库（iconfont）
  - CDN: //at.alicdn.com/t/font_xxxxx.js
  - 图标：搜索图标（icon-search）

## 4. 交互规范

### 4.1 基础交互
- 输入框聚焦效果：边框发光
- 价格卡片悬停：轻微上浮 + 边框高亮
- 按钮点击：缩放反馈

### 4.2 动画效果
- 页面加载：淡入动画
- 卡片悬停：过渡动画 0.3s ease
- 液态流动感：使用伪元素实现光晕效果

---

## 5. 响应式设计

### 5.1 断点设置
- 桌面端：> 1024px
- 平板端：768px - 1024px
- 移动端：< 768px

### 5.2 适配策略
- 价格模块：桌面端横排，平板和移动端竖排
- 输入框：全宽度自适应
- LOGO：根据屏幕尺寸缩放
